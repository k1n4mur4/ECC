# ECC スキルコントリビューションレビューパケット

このワークフローを使用して、メンテナーによるレビューのためにスキルコントリビューションの観察結果を準備します。
このバージョンは、`skills/` 配下の正規ソースを持つ `changeKind: "skill"` をサポートします。
これは提供された観察結果をまとめるものであり、Git、ファイル、CI、テスト結果、カバレッジ、参照されている証拠を独自に調査することはありません。
取り込まれたすべての主張は、レビュアーが証拠を確認するまで未検証として扱ってください。

## ワークフロー

1. アクティブな ECC チェックアウトから開始します。ブランチ、ベースと HEAD、パッケージロック、インストールマニフェスト、カタログジェネレーター、スキル配置ポリシー、チェックポイントを記録します。
2. キュレーションされたワークフローについて、`skills/` 配下の正規ソースを特定します。生成されたコンテンツ、学習されたコンテンツ、インポートされたコンテンツは、出荷されるソースの外に置いてください。
3. 変更の意図、アーティファクトグラフ、インストールのカバレッジ、ハーネスのコピー、カタログとレジストリの件数、テストフェーズ、カバレッジ、セキュリティレビュー、予算、コミット提案を、証拠への参照とともに記録します。
4. 必須のバリデーターとテストを個別に実行します。正確なコマンド、結果、証拠を記録します。コンパイラーはこれらを実行しません。
5. テンプレートをコピーし、そのコピーを編集して、すべてのプレースホルダーを現在の観察結果と、自分が収集した証拠への参照に置き換えます。テンプレートは意図的に未完成であり、観察結果として扱ってはいけません。
   編集後に、パケットをコンパイルします。

   ```bash
   mkdir -p .memory-kit
   cp skills/ecc-contribution-review/templates/contribution-review-observation.json \
     .memory-kit/contribution-review-observation.json
   python3 skills/ecc-contribution-review/scripts/compile_contribution_review.py \
     .memory-kit/contribution-review-observation.json \
     --output .memory-kit/ecc-contribution-review.json
   ```

   `--output` は、既存の親ディレクトリに新しいカプセルファイルを書き込み、既存のパスがあっても上書きしません。コンパイラーは、ディレクトリの作成、ソースファイルの変更、テストの実行、カタログの更新、コミット、プッシュ、プルリクエストのオープンを行いません。終了コード 0 は、報告されたフォールトや矛盾なしにパケットが出力されたことを意味しますが、レビューは依然として必要です。終了コード 2 は、検証フォールト、矛盾、または入出力エラーを意味します。終了コード 2 でも診断用のパケットが出力されることがあります。パケットと stderr を確認してください。終了コードだけでは出力の有無は判断できません。

6. 報告されたすべての矛盾とセマンティックページフォールトをレビューします。コンパイラーは、構造的に有効な入力に対して `require_review` を返し、コントリビューションを承認することはありません。提供された主張が真であること、または CI が通過したことを証明するものでもありません。
7. HEAD、ポリシー、マニフェスト、カタログ、アダプター、テスト、カバレッジ、セキュリティ上の指摘、レビューの証拠に変更があった場合は、再コンパイルしてください。

## ローカルコントラクト

パケットは、ソースの所有権、生成ルートの除外、インストールのカバレッジ、正規化されたハーネス ID、カタログの照合、TDD の主張、セキュリティレビュー、検証ゲート、Conventional Commit の提案を記述します。ランナーの提案は型付きの引数配列であり、実行されないままです。生成されるすべての権限と外部への影響は false のままです。

[ワークフロー](../../../../skills/ecc-contribution-review/docs/WORKFLOW.md)、[設計](../../../../skills/ecc-contribution-review/docs/DESIGN.md)、[コントラクト](../../../../skills/ecc-contribution-review/references/contribution-review-contract.md)を参照してください。JSON 入力は説明用のフィクスチャであり、現在のリポジトリの観察結果ではありません。
