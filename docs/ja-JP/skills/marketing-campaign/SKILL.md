# マーケティングキャンペーン

出荷するだけでなく、成果につながるローンチキャンペーンを計画し、実行します。

## 有効化するタイミング

- 製品や機能のローンチを計画するとき
- 1 つのプロダクトブリーフから完全なコンテンツ一式を構築するとき
- コピーを書く前にポジショニングとキャンペーンアングルを定義するとき
- 複数のコンテンツタイプをチャネル横断でオーケストレーションするとき
- コンバージョン品質とブランドの一貫性の観点でコピーをレビューするとき

## 譲れない原則

1. コピーを書く前にポジショニングを定義します。すべてのコピーはアングルから生まれます。
2. オーディエンスの言葉や不安を知っているつもりにならず、先にリサーチします。
3. 各成果物は、キャンペーンの流れの中で明確な 1 つの目的を果たさなければなりません。
4. あらゆるフォーマットとチャネルで、形容詞よりも具体性が勝ります。
5. すべてのチャネル、すべての作品で同じボイスを貫きます。
6. 品質ゲートを通過していないコピーは出荷しません。

## キャンペーンワークフロー

### フェーズ 1: リサーチ

`market-research` を使って次を行います。
- ターゲットオーディエンスのプロファイルを作成する（ジョブ理論（Jobs-to-be-Done）、不安、言葉遣い、利用している代替手段）
- 直接的または隣接する競合を 3 社以上マッピングする（ポジショニング、ギャップ、メッセージングの弱点）
- キャンペーンアングルが活用する 1〜3 件のオーディエンスインサイトを特定する

成果物: 短いリサーチブリーフ（オーディエンスプロファイル + 競合サマリー + 主要なインサイト）。

### フェーズ 2: ポジショニング

次を作成します。
- コアベネフィットステートメント（1 文、機能の羅列なし、専門用語なし）
- ポジショニングの公式: 「[Product] は [audience] が [mechanism] によって [achieve outcome] できるよう支援します」
- キャンペーンアングル: キャンペーン全体が拠って立つ具体的な緊張、インサイト、または瞬間
- トーンプロファイル: 執筆前に確定する（セッションをまたいで再利用できる永続的なボイスのキャプチャは `brand-voice` に委任する）

ポジショニングとアングルが承認されるまで、コピーは一切書かないでください。

### フェーズ 3: コンテンツ制作

次の順序で制作します。各レイヤーが次のレイヤーに情報を与えます。

1. **ランディングページのコピー**（全セクション: ヒーロー、課題、解決策、機能、仕組み、実績、CTA）
2. **メールシーケンス**（各メールの目的は 1 つ。流れに従う: 課題 → 教育 → 課題の深掘り → 解決策 → 実績 → 緊急性 → 最終 CTA）
3. **ソーシャル投稿**（`content-engine` によるプラットフォームネイティブな投稿。LinkedIn と X は別のフォーマットであり、同じコピーのサイズ違いではありません）
4. **ショート動画スクリプト**（タイムスタンプでブロック化。ページ向けではなく、画面と耳のために書く）
5. **広告コピーのバリエーション**（異なるアングルやオーディエンスセグメントを試す 3〜4 種類）
6. **コンテンツカレンダー**（チャネル、種類、タイミング、依存関係を含む日別スケジュール）

### フェーズ 4: レビュー

すべての成果物にゲートを設けます。
- すべてのヒーロー / ファーストビューのコピーに対する 5 秒テスト（誰のためのものか、何をするものか、なぜ今行動すべきかが明確であること）
- CTA の監査（1 つの作品につき 1 つ、具体的で、押し付けではなく、読者が自然に行動したくなる根拠を示したもの）
- 全チャネルにわたるトーンの一貫性チェック
- 主張の監査（すべての主張が具体的で、裏付け可能であること）
- チャネル間の一貫性（広告の主張がランディングページと一致し、メール本文が件名と一致していること）

## 出力契約

完全なキャンペーンは次を納品します。

1. **ポジショニングブリーフ** — アングル、コアベネフィットステートメント、トーンプロファイル
2. **ランディングページのコピー** — ヒーロー、課題、解決策、機能、仕組み、実績、CTA
3. **メールシーケンス** — 各メールの件名 + プレビュー + 本文 + CTA。日と目的でラベル付けする
4. **LinkedIn 投稿** — 異なるアングルを持つ、プラットフォームネイティブな 3 件以上の投稿
5. **X 投稿** — 単独の投稿 5 件以上 + スレッド 1 本
6. **ショート動画スクリプト** — ビジュアル演出メモ付きのタイムスタンプブロック化されたスクリプト 2 本以上
7. **広告コピーのバリエーション** — バリエーションごとに短い見出し / 長い見出し / 本文
8. **コンテンツカレンダー** — チャネル、コンテンツタイプ、タイミング、依存関係を含む日別スケジュール
9. **コピーレビューサマリー** — 公開前に指摘された問題点と未解決の疑問点

## 品質ゲート

どの成果物も、納品前に次を確認します。

- すべての成果物が同じ著者によるものに聞こえる
- 中身のない最上級表現や埋め草の形容詞が残っていない
- すべての CTA が具体的で、読者が自然に行動したくなる根拠を示している（「learn more」や「click here」は不可）
- プラットフォーム間でコピーが一字一句そのまま重複していない
- ヒーローコピーが 5 秒テストを通過している
- メールの件名が本文と一致している（釣り広告のような件名と本文の食い違いがない）
- 広告の主張がランディングページの主張と完全に一致している
- 同じカテゴリーの他の製品にそのまま使えてしまうコピーがない

## 禁止表現

次のものは削除して書き直してください。

- 「game-changing」「revolutionary」「world-class」「cutting-edge」
- 「In today's competitive landscape」
- 実際の期限の裏付けがない偽の緊急性
- 具体性を欠いた社会的証明（「何千人もが信頼しています」）
- 汎用的な CTA（「learn more」「find out more」「click here」）
- そのまま競合のキャンペーンに差し替えられてしまうコピー

## 関連スキル

- `brand-voice` — ソース由来のボイスのキャプチャ（コンテンツ制作の前に実行）
- `content-engine` — プラットフォームネイティブなコンテンツ制作
- `crosspost` — マルチプラットフォーム配信
- `market-research` — オーディエンスと競合のインテリジェンス
- `seo` — ランディングページコピーのオンページ最適化
