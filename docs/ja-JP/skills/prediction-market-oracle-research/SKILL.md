# 予測市場オラクル調査

予測市場を、データソース、予測の入力、オラクル的なシグナル、または意思決定インテリジェンス層として検討している場合に、このスキルを使用します。

## ガードレール

- 市場価格を客観的な真実として扱わないでください。
- 投資助言や取引の推奨を行わないでください。
- 取引所の仕組み、流動性、インセンティブ、解決ルールを、市場が織り込むシグナルと切り分けて扱ってください。
- 価格操作、薄い流動性、更新が止まった市場、曖昧な結果判定を明示してください。
- オンチェーンまたは実行と連動するシステムでは、書き込み権限を付与する前に `llm-trading-agent-security` を実行してください。

## 調査ワークフロー

1. このシグナルが判断材料を提供する対象となる意思決定を定義します。
2. 関連する市場、イベント、タグ、取引所を探します。
3. 市場が織り込む確率を、タイムスタンプと出典リンクとともに記録します。
4. シグナルの品質を評価します。
   - 流動性
   - スプレッド
   - 市場の経過期間
   - 判明している場合は、トレーダー／インセンティブの集中度
   - 解決権限
   - 地域やアカウントの制限
5. 提出書類、ニュース、世論調査、研究、顧客データ、社内 KPI などの非市場ソースと比較します。
6. 示された意思決定に対して、シグナルが使用可能か、弱いか、不適切かを推奨として示します。

## 統合パターン

- リサーチアシスタント: 人間のアナリスト向けの、出典に基づいたコンテキスト。
- ダッシュボードシグナル: 社内指標と並べて表示する、市場が織り込む確率。
- エージェントメモリ入力: 後で取得できる、タイムスタンプ付きのシグナル。
- アラート入力: 確率、スプレッド、流動性がしきい値を超えたときに通知する用途。
- シナリオプランニング: 取引を自動化せずに、複数のイベント結果を比較する用途。

## 出力規約

次の構成を使用します。

1. 意思決定のコンテキスト
2. 市場ソース
3. シグナルの品質
4. 比較ソース
5. 統合の推奨事項
6. 注意点

最後に次の文を添えます。

```text
Prediction-market signals are informational inputs, not investment advice.
```
