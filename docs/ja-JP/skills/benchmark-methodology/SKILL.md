# ベンチマーク方法論

このスキルは、スコープ化された競合セットを**比較可能で根拠のあるスコア**に変換するために使用します。各競合は同じ 9 つのディメンションで評価され、明示的な 1〜5 のルーブリックを用いたうえで、統一されたプロファイルカードにまとめられます。重要なのは一貫性です。スコアが有用なのは、同じエビデンスであればどの競合にも同じ数値が付く場合に限られます。

## 使用タイミング

- competitive-platform-analysis で作成された、スコープ化・階層化済みの競合セットがスコアリングできる状態にある。
- 直感的なランキングではなく、競合間で比較可能でエビデンスに基づくスコアが必要。
- クライアントの戦略的テンション（ターゲットとするホワイトスペースを定義する対の軸）が確立されている。
- competitive-report-structure で組み立てるためのプロファイルカードを作成する準備をしている。

## クライアントのポジショニングブリーフ（最初に確立する）

スコアリングの前に、クライアントのポジショニングブリーフを確立します。ブリーフには次の内容が含まれます。

- **戦略的テンション** — 2 本の軸（例: 記憶に残りやすさ × 採用しやすさ）。その交点がクライアントのターゲットとするホワイトスペースを示します。ディメンション 9 は常にクライアントが定めたテンションであり、両極を平均せず、別々に報告します。
- **差別化要因** — クライアントの堀（モート）となるもの。クライアントのポジショニングの主張にとってどのディメンションが最も重要かを決める材料になります。
- **ブランドバランス** — 意図された、異なる戦略的強調点の組み合わせ。戦略的な提言は、フラグを立てずにこのバランスを崩してはなりません。

## これらのディメンションを使う理由

クライアントは、サービスの幅広さではなく、**2 つの極にまたがって保たれる特定のテンション**で競争しています。ディメンションは、その堀を反映するように重み付けされています。2 つのディメンション（テンションの両極）は**別々にスコアリングされ、決して平均されません**。クライアントの戦略的な問いは、まさにライバルが両方を同時に達成しているかどうかだからです。

## 9 つのディメンション（重み付き）

重みは、単一の合成スコアではなく、統合時に何を重視するかの指針です（誤った合成値を避けるため。バイアス対策を参照）。合計は 100% です。

1. **ポジショニングの明確さと独自性**（18%） — スタジオのポジションは鋭く、自社だけのものとして成立し、一目で理解できますか。それとも一般的ですか。
2. **ブランドボイス / 言語面の独自性**（15%） — コピーに自社固有のトーンがあるか、それとも誰にでも当てはまるエージェンシー用語で済ませているか。
3. **ビジュアルアイデンティティとサイトのクラフト**（15%） — ビジュアルシステムの品質と独自性。クラフトの証明としてのサイト。
4. **サービスオファーとパッケージング**（12%） — プロダクト化され分かりやすい（名前の付いたスプリントや監査）か、曖昧か。パッケージングの成熟度。
5. **エビデンスと信頼性**（12%） — 実名のクライアント、定量化された成果、ケーススタディの深さ。主張を超えた証拠。
6. **エンタープライズ対応力 / 商業的成熟度**（10%） — SaaS／フィンテック／B2B／エンタープライズの案件を獲得し、維持できるというシグナル（プロセス、ロゴ、規模、契約）。
7. **ソートリーダーシップ / コンテンツプレゼンス**（8%） — 自社の視点の保有。執筆、登壇、ニュースレター、フレームワーク。量よりも深さ。
8. **価格の透明性とエンゲージメントモデル**（5%） — 価格やエンゲージメントが分かりやすいか。プロダクト化、個別対応、不透明のいずれか。
9. **[クライアントの戦略的テンション]**（フラグとして 5%。**両極をスコアリングし、別々に報告する**） — テンション名と軸の説明は、クライアントのポジショニングブリーフから読み取ります。両方をプロットします。そのギャップこそが洞察です。クライアントのターゲット象限は最も重要な発見事項です。つまり、すでにそこにいるのは誰か、ということです。

## スコアリングルーブリック（1〜5、ディメンション 1〜8 に適用）

すべてのスコアを観察可能なエビデンスに結び付けます。以下は一般的な記述子です。ディメンションごとに具体的な内容は調整しつつ、各レベルの意味は一定に保ちます。

- **1 — 不在 / 一般的。** 識別できるポジションやクラフトがなく、テンプレートと区別がつかない。むしろ負債。
- **2 — 水準以下。** 意図は見られるが、一貫性がない、二番煎じ、または説得力に欠ける。並べて比較されると持ちこたえられない。
- **3 — 十分 / 最低限の水準。** 堅実でプロフェッショナルだが、特筆すべき点はない。期待は満たすが、誰の専有物にもなり得ない。
- **4 — 強い / 独自性がある。** 同業他社より明らかに優れ、買い手が気づいて挙げるような本物の強み。
- **5 — カテゴリーを定義する。** 最高水準で、自社固有のものであり、模倣が難しい。他社が反応する基準を打ち立てている。

### テンション軸（ディメンション 9） — 各軸を 1〜5 でスコアリング

軸のラベルとその 1/3/5 のアンカーは、クライアントのポジショニングブリーフから読み取ります。記憶に残りやすさ × 信頼性というテンションでのアンカー例は次のとおりです。

- **記憶に残りやすさ** — 1: すぐに忘れられる · 3: 文脈の中なら認識できる · 5: 忘れられない、話題になる、独自のものとして確立されている。
- **信頼性** — 1: 危うい／素人っぽく感じる · 3: 安全で有能だが刺激がない · 5: エンタープライズから信頼され、明らかに安全な選択肢。

競合をテンション 2×2 にプロットします。クライアントのターゲット象限は、ポジショニングブリーフで名前が付けられています。その象限に他に誰がいるかが、このベンチマークで最も重要な発見事項です。

## データの収集方法

各競合について、次の順序でディメンションを進めます（最も低コストなシグナルから）。

1. **競合自身のサイト** — ポジショニング、ボイス、オファーのパッケージング、価格設定の姿勢、実名のクライアント、マニフェスト／視点。ホームページとケーススタディ 1 件のスクリーンショットを撮ります。
2. **ケーススタディ / 実績** — エビデンスの深さ、定量化された成果、クライアント名。*主張されたもの*（「X を提供した」）と*証明されたもの*（指標、実名、検証可能）を区別します。
3. **レビューディレクトリ** — クライアント、プロジェクト規模、エンゲージメントモデルを裏付け、信頼性とエンタープライズ対応力を評価します（例: Clutch.co またはそのニッチ分野の同等サービス）。
4. **LinkedIn** — チーム規模／モデル、創業者のナラティブ、コンテンツの発信頻度から、ソートリーダーシップとモデルを評価します。
5. **ポートフォリオ / クラフトプラットフォーム** — クラフトの水準（そのニッチ分野固有のショーケースを使用: デザインボード、ショーリール、公開サンプルなど）。
6. **コンテンツチャネル** — ニュースレター／登壇／執筆から、ソートリーダーシップの深さを評価します。

**ディメンションごとに記録するもの:** スコア、1 行の根拠、そのスコアの根拠となったソースのリンク／スクリーンショット。エビデンスのないスコアは付けません。

## バイアス対策

- **単一の合成スコアは作らない。** ディメンションごとのスコアとテンションプロットを別々に報告します。加重平均は、重要な非対称性を隠してしまいます。
- **主張と証明の区別。** 裏付けのない自己申告の主張については、信頼性／エビデンスのスコアを下げます。サイトのコピーはマーケティングであり、事実ではありません。
- **美的親和性バイアス。** レビュアーは、自分が共感する美学を持つスタジオを過大評価し、ライバルの商業的な強さを過小評価しがちです。クラフトと信頼性は独立してスコアリングします。「地味」なサイトが、より大きなクライアントを獲得していることもあります。
- **直近性 / 派手さバイアス。** 受賞歴のあるショーピース的な作品は目を引きますが、商業的な深みに欠けることがあります。信頼性をスコアリングする前に、ディレクトリやクライアントで検証します。
- **生存者バイアス。** 目立ってよくマーケティングされているスタジオが市場のすべてではありません。ディレクトリやレビューで見つかる、強いが目立たない事業者も記録します。
- **単独ではなくセット全体で較正する。** 確定する前に、スコアを並べて読み直します。「4」はすべての競合で同じ意味でなければなりません。外れ値は調整します。

## 競合プロファイルカード（出力フォーマット）

プロファイル対象の競合ごとに 1 枚のカードを作成します。これはレポートが組み立てられる際の最小単位です。

```
## <Competitor name>
- **Profile / Tier:** <positioning stance · specialization · size band> / <Direct | Adjacent | Aspirational>
- **One-liner:** <how they position themselves, in their words>
- **Model / size / geography:** <solo|micro|boutique> · <region> · <pricing/engagement model>
- **Notable clients / evidence:** <named, with proven/asserted tag>

### Dimension scores
| Dimension | Score (1–5) | Justification (1 line) | Source |
|---|---|---|---|
| Positioning clarity & distinctiveness | | | |
| Brand voice / verbal distinctiveness | | | |
| Visual identity & site craft | | | |
| Service offer & packaging | | | |
| Evidence & credibility | | | |
| Enterprise-readiness / commercial maturity | | | |
| Thought leadership / content presence | | | |
| Pricing transparency & engagement model | | | |

### Tension plot
- **[Axis 1 from positioning brief]:** <1–5> — <why>
- **[Axis 2 from positioning brief]:** <1–5> — <why>
- **Quadrant:** <high/high | high-1/low-2 | low-1/high-2 | low/low>

### Read for [client]
- **Strength to learn from:** <…>
- **Weakness to exploit / white-space it exposes:** <…>
- **Threat to [client]:** <…>
```

完成したカードとテンションプロットを `competitive-report-structure` に渡します。

## アンチパターン

- **テンション軸の平均化。** クライアントの戦略的テンションの両極は、別々にスコアリングして報告しなければなりません。平均化すると洞察が失われます。両極のギャップこそが発見事項です。
- **エビデンスなしのスコアリング。** すべてのスコアには 1 行の根拠とソースリンクが必要です。エビデンスのないスコアは意見であって、ベンチマークではありません。
- **単一の合成スコアの作成。** ディメンションスコアは個別に報告します。加重平均は、ポジショニングにとって重要な非対称な強みを隠してしまいます。
- **調整なしでの一般的なルーブリックのアンカー適用。** 1〜5 のアンカーは、特定のディメンションと競合セットに合わせて較正しなければなりません。一般的な記述は出発点であり、固定された基準ではありません。
- **競合セットのスコープ化前の実行。** まず competitive-platform-analysis を使用して、階層化・絞り込み済みのセットを作成します。スコープ化されていないリストをスコアリングすると、無関係な競合に労力を浪費します。

## 関連スキル

- `competitive-platform-analysis` — 前提となるスキル。このスキルがスコアリングする、階層化された競合セットを作成します。
- `competitive-report-structure` — 次のステップ。スコアリングされたプロファイルカードを、クライアント向けの成果物レポートに組み立てます。
