# 予測市場リスクレビュー

予測市場のワークフローがユーザーの金融コンテキスト、取引所の認証、ポートフォリオデータ、自動化、実行可能なツールに触れる前に、このスキルを使用します。

## レビューゲート

### アドバイスの境界

- 出力が情報提供的なものであることを確認します。
- 買い/売り/保有の推奨や取引サイズ（ポジションサイズ）の推奨を取り除きます。
- ユーザーが手動で判断するポイントを明示したままにします。

### 取引所と規制の境界

- 取引所の利用規約、地域制限、アカウント上限、API ルールを特定します。
- 該当する場合、賭博、デリバティブ、証券、コモディティのいずれに当たるかが曖昧な点を、法務レビュー対象として指摘します。
- 取引所の制限やレート制限を回避しないでください。

### データ品質

- 市場の流動性、スプレッド、解決ルール、古い価格、ソースのタイムスタンプを確認します。
- 公開されている取引所データと Itô のアクセス制限付きデータを分離します。
- 公開ソースと非公開ソースをラベルなしで混在させないでください。

### セキュリティ

- 秘密鍵、シードフレーズ、パスワードを要求または保存しないでください。
- `ITO_API_KEY` と取引所の API キーをログやドキュメントに含めないでください。
- デフォルトで読み取り専用のスコープを使用します。
- 非公開の実装が実行機能を追加する前に、サーキットブレーカー、支出上限、ドライラン、人間による承認を必須とします。

### プライバシー

- ユーザーのポートフォリオ、金融、ナレッジベースのデータを最小限にします。
- 公開成果物では非公開ソースをマスクします。
- レビューに必要なフィールドのみを保持します。

## 出力契約

次を返します。

1. レビューした範囲
2. pass/warn/fail の所見
3. ブロックされたアクション
4. 必要な緩和策
5. 安全な次のステップ

実行可能なステップが要求された場合は、別個の実装計画とユーザーの明示的な承認を必須とします。
